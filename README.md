# Habit Tracker

## Note: Work in Progress

## MVP

The user should be able to create an account, log in, add new habits, select the target frequency, eg. every day, 3x a week, so on so forth, track their own progress, see what their current streak is, see their longest ever streak, visualize it over a calendar.

## Technologies

Made with flask and angular, using sqlite for the database. Might seem confusing, given im a react + express dev that uses nosql most of the time, but i felt it would be nice to spend a couple of days working on a fullstack project outside of my comfort zone, and learn something new too! Most of the work will be done on the backend, so the frontend remains quite light, im doing authentication using jwt, and for the analytics bit i will be sending the already ready to use data from the backend, not a random concoction that i have to refactor before using. This makes the backend of this project heavier, but more reusable for the future.

Im also gonna use this project to consolidate how to work with CI / CD, E2E testing, and Docker, ive worked with these stuff in the past, but its either been a while since ive used them, or i havent worked with them to this extent.
